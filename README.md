# Fussy Shapes

Use Node.js 22.12 or newer and run `npm ci`, then `npm run serve`.
Open the local address printed by the server.

The application is in `index.html`, `sketch.js`, `fussy-shapes.css`, and `assets`.
Installed packages are generated from `package-lock.json` and are not committed.
Run `npm audit` to check the development server dependencies.
